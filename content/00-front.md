# Git Internals for Software Forensics

You already use Git every day. This primer explains the few ideas underneath it: enough to see why two matching hashes can settle a question about thousands of files, and where a hash stops being evidence.

Every hash and every piece of command output below comes from a small demo repository that a script builds from scratch, so you can rebuild it and follow along. Reading time is about 20 minutes. A cheat sheet is at the end.
